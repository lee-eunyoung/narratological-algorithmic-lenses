# 연구진행 매뉴얼 (Research Roadmap Guide)
## 치매 조기검진 기반 인지단계별 간호중재 프로토콜 개발 — 델파이 연구

> **이 문서의 목적**: "연구를 실제로 어떤 순서로, 각 단계에서 **무엇을 준비/지참**하여
> 진행하는가"를 막막함 없이 따라갈 수 있도록 단계별로 정리한 **실행 안내서**다.
> 이 가이드가 **주(主) 문서**이며, 세부 설계·도구·제안서는 부속 문서(01~04)로 연결된다.
>
> **읽는 법**: 각 단계는 ① 무엇을 하는가 → ② 준비물·지참물 체크리스트 → ③ 산출물 →
> ④ 예상 소요기간 → ⑤ 흔한 실수 순서로 되어 있다. 특히 **1~3단계**를 가장 자세히 다룬다.

---

## 한눈에 보는 전체 로드맵

```
0단계 준비        1단계 항목도출           2단계 델파이 1R        3단계 델파이 2~3R       4단계 마무리
─────────       ──────────────         ─────────────        ──────────────        ───────────
주제·틀 확정  →  문헌+조기검진+EMR   →   패널 구성·1차설문  →  수렴·합의(CVR)    →   타당도보고·논문
IRB 준비         예비 항목 매트릭스       개방형 의견 수집       최종 도구 확정         결과 해석
(4~8주)          (8~12주)                (4~6주)               (6~10주)              (8~12주)
```

| 단계 | 핵심 질문 | 가장 중요한 산출물 |
|------|----------|-------------------|
| 0 | 무엇을, 왜, 누구 승인으로 하나? | 연구계획서 + IRB 승인 |
| 1 | 평정할 **항목**은 어디서 오나? | 단계별 간호진단·중재·평가 **예비 매트릭스** |
| 2 | 누가 평정하고, 어떻게 묻나? | 전문가 패널 + 1라운드 응답 데이터 |
| 3 | 언제 **합의**됐다고 보나? | 합의된 **최종 간호 프로토콜** |
| 4 | 결과를 어떻게 보고·해석하나? | 타당도 보고서 + 학위논문 |

> **전체 예상 기간: 약 7~12개월** (IRB 심의·패널 회수율에 따라 변동)

---

## 0단계 — 준비 (FRAME)

### ① 무엇을 하는가
- 연구 주제·질문·목적을 확정하고 지도교수와 합의한다.
- 연구설계를 "단계 간 차이 **검정**"이 아니라 **"단계별 차별화된 간호 프로토콜의 개발 및
  전문가 합의(내용타당화)"**로 확정한다. → 상세 근거는 `01-research-design.md`.
- 단계 분류 기준(정상 / MCI / 치매[경도·중등도·중증])을 **CDR 또는 GDS** 중 하나로 확정한다.
- 두 데이터 소스의 **역할**을 분리한다(아래 1단계 참조).
- IRB(생명윤리위원회) 제출을 준비한다.

### ② 준비물·지참물 체크리스트
- [ ] 확정된 연구계획서 초안(`04-proposal-draft.md` 기반)
- [ ] 지도교수 승인·서명
- [ ] 단계 분류 기준 확정 문서(CDR vs GDS 선택 근거)
- [ ] IRB 신청서, 연구대상자 설명문·동의서(전문가 패널용 + [후향자료 사용 시] 자료이용 동의/면제 사유)
- [ ] 데이터 출처별 기관 협조 공문 초안 (치매안심센터 / 병원 의무기록팀)
- [ ] 개인정보·민감정보 처리계획(가명처리·보관·폐기)

### ③ 산출물
- 확정 연구계획서, IRB 승인서(또는 심의면제 확인서)

### ④ 예상 소요기간
- **4~8주** (IRB 정규심의는 회의 일정에 따라 추가 4~8주 소요 가능 — 일찍 제출하라)

### ⑤ 흔한 실수
- ✗ "단계 간 차이를 통계로 검증" 식으로 목적을 쓰면 심사에서 방법-목적 불일치 지적을 받는다.
  델파이는 **합의·내용타당화** 도구다(`01` 참조).
- ✗ IRB를 마지막에 준비 → 전체 일정이 밀린다. **0단계에서 바로 착수**.
- ✗ 단계 분류 기준을 모호하게 두면 1단계에서 자료 정렬이 불가능해진다.

---

## 1단계 — 항목 도출 (가장 막막한 단계 ①)

> **이 단계의 본질**: 델파이에서 전문가가 평정할 **"예비 항목"을 만드는 단계**다.
> 항목이 부실하면 이후 전부가 흔들린다. 항목의 출처(derivation path)를 분명히 한다.

### ① 무엇을 하는가
**세 갈래 입력**을 모아 **단계별 간호 매트릭스(예비 항목)**를 만든다.

1. **문헌고찰** — `02-literature-review.md`에서 확인된 근거를 항목 후보로 변환.
   - 예: 운동중재(Huang et al., 2022), 비약물중재, 단계별 케어 요구 등.
2. **치매 조기검진 평가자료** — **"인지단계 분류 축"** 역할.
   - CIST/과거 MMSE-DS, 진단평가(SNSB·CERAD-K), CDR·GDS → 대상자가 **어느 단계**인지 규정.
   - 단계별 대상자 특성(인지·일상생활수행·행동심리증상 BPSD)을 기술 통계로 파악.
3. **EMR 간호기록** — **"간호 항목의 내용"** 역할.
   - 실제 작성된 간호진단(NANDA-I/표준간호용어)·간호중재(NIC)·간호경과·평가(NOC) 기록을
     후향적으로 추출 → 단계별로 어떤 간호가 실제 수행되는지 항목화.

> **두 자료의 결정적 차이(반드시 숙지)**
> | | 조기검진 평가자료 | EMR 간호기록 |
> |--|--|--|
> | 역할 | 인지단계 **분류 축** | 간호 **항목 내용** |
> | 성격 | 횡단·지역사회·**초기 편중** | 종단·임상/요양·**중등도~중증 포함** |
> | 접근/IRB | 치매안심센터·지자체 협조 | 병원 IRB·의무기록 열람 |
> → **별개의 작업 흐름**으로 진행하되, **동일 단계분류 기준(CDR/GDS)으로 재정렬**해야
> 단계 간 비교가 성립한다. (자세히는 `01-research-design.md`)

그 다음, 세 입력을 종합해 **간호과정(NANDA-I → NIC → NOC) 매트릭스**를 만든다.

| 인지단계 | 간호진단(NANDA-I) | 간호중재(NIC) | 간호평가(NOC) |
|---------|-------------------|---------------|---------------|
| 정상(검진 정상군) | … | … | … |
| MCI | … | … | … |
| 치매-경도 | … | … | … |
| 치매-중등도 | … | … | … |
| 치매-중증 | … | … | … |

### ② 준비물·지참물 체크리스트
- [ ] IRB 승인서(0단계 산출물)
- [ ] 문헌 근거표(`02-literature-review.md`) + 국내 DB(RISS/KCI) 추가 검색분
- [ ] 조기검진 자료 접근 승인 + **변수 사전(data dictionary)**: 어떤 검사·점수가 있는지
- [ ] EMR 간호기록 추출 권한 + 표준간호용어 매핑표(NANDA-I/NIC/NOC 또는 기관 표준)
- [ ] 단계 분류 규칙표(예: CDR 0=정상, 0.5=MCI, 1=경도, 2=중등도, 3=중증)
- [ ] 자료 추출·정리용 도구(엑셀/통계패키지), 가명처리 절차

### ③ 산출물
- **단계별 간호진단·중재·평가 예비 항목 매트릭스** (= 델파이 1라운드 설문의 원재료)
- 단계별 대상자 특성 기술통계표
- → 이 매트릭스는 `03-delphi-instrument.md`의 1라운드 문항으로 직행한다.

### ④ 예상 소요기간
- **8~12주** (두 자료의 접근 승인·추출이 병목; 일찍 신청)

### ⑤ 흔한 실수
- ✗ 조기검진 자료와 EMR을 **같은 것으로 섞기** → 모집단·단계 범위가 달라 비교 정합성이 깨진다.
- ✗ 항목 출처를 적지 않기 → 심사에서 "이 항목 왜 들어갔나?"에 답할 수 없다. **항목마다 출처 표기**.
- ✗ 조기검진은 초기 단계에 편중되어 **중증 단계 항목**이 비게 됨 → EMR/문헌으로 보완하고
  한계로 명시.
- ✗ 항목 수 과다(평정 피로) — 1라운드는 폭넓게, 이후 라운드에서 수렴.

---

## 2단계 — 델파이 1라운드 (가장 막막한 단계 ②)

### ① 무엇을 하는가
- **전문가 패널을 구성·섭외**한다.
- 1단계의 예비 매트릭스를 **평정형 설문 + 개방형 의견란**으로 구성해 1차 배포한다.
- 각 항목의 **적절성/중요도**를 평정(보통 4점 또는 5점 Likert)하게 하고, 누락 항목·수정
  의견을 자유응답으로 받는다.

### ② 준비물·지참물 체크리스트
- [ ] **전문가 패널 명단** — 자격기준 충족자 (아래)
  - 치매 전문 간호사/노인전문간호사, 치매안심센터 실무자, 간호학 교수, 노인의학·신경과 의사,
    경력(예: 임상 5년+ 또는 박사) 기준 충족
  - **표본수**: 통상 **10~20명**(동질 패널 10명 이상이면 운용 가능 — de Oliveira Riboldi
    et al., 2015). 이질 패널이면 더 크게.
- [ ] 패널 초청장·연구설명문·**서면동의서**
- [ ] 1라운드 설문지(평정척도 + 개방형) — 온라인 폼(구글폼/서베이몽키 등) 또는 이메일
- [ ] 항목별 출처·정의가 담긴 **안내문**(평정 기준을 통일)
- [ ] 응답 기한·리마인더 계획(회수율 관리)
- [ ] 분석 계획서: CVR·평균·표준편차·변동계수 산출 방법(`03` 참조)

### ③ 산출물
- 1라운드 응답 데이터셋(항목별 평정 분포 + 개방형 의견)
- 1라운드 분석표(항목별 CVR, 평균, 합의·수렴 지표)

### ④ 예상 소요기간
- **4~6주** (섭외 2~3주 + 응답·회수 2~3주)

### ⑤ 흔한 실수
- ✗ 패널 선정 기준을 사후에 정하기 → **사전에 명문화**(자격·경력·전문분야 분포)해야 타당성 확보.
- ✗ 개방형 의견란 생략 → 누락 항목을 발굴할 기회를 잃는다(델파이의 핵심 강점).
- ✗ 회수율 관리 실패 → 중도탈락은 합의 안정성을 해친다. 리마인더·기한을 설계에 포함.
- ✗ 평정척도와 합의 기준을 1라운드 후 바꾸기 → 사전 고정.

## 3단계 — 델파이 2~3라운드 및 합의 (가장 막막한 단계 ③)

### ① 무엇을 하는가
- 1라운드 결과(항목별 통계 + 익명화된 패널 의견)를 **피드백**으로 동봉해 2라운드를 배포한다.
- 패널은 집단 응답을 보고 **재평정**한다 → 의견이 **수렴**한다.
- **합의 기준**을 적용해 항목을 **채택/수정/탈락**시킨다.
- 합의·안정성이 충족되면 종료(보통 2~3라운드), **최종 간호 프로토콜**을 확정한다.

### ② 준비물·지참물 체크리스트
- [ ] 1라운드 분석 결과(항목별 통계) + 익명 의견 요약(피드백 자료)
- [ ] 수정·추가된 항목이 반영된 2라운드 설문지
- [ ] **합의 판정 규칙(사전 확정)** — 아래 ④ 기준표
- [ ] 라운드 종료 판정 기준(안정도 충족 or 최대 라운드 도달)
- [ ] 분석 도구(CVR 임계값표, 변동계수·수렴도·합의도 계산식 — `03` 참조)

### ③ 합의·판정 기준 (요약 — 상세 계산은 `03-delphi-instrument.md`)
- **내용타당도비율 CVR (Lawshe)**: 패널 수에 따른 임계값을 넘는 항목만 채택.
  - 예) 패널 10명 → CVR ≥ 0.62, 15명 → ≥ 0.49, 20명 → ≥ 0.42 (Lawshe 기준표).
- **내용타당도지수 CVI**: 항목 I-CVI ≥ 0.78, 척도 S-CVI ≥ 0.90 권장.
- **안정도(stability)**: 변동계수 **CV ≤ 0.5**(또는 ≤0.8) → 라운드 간 응답이 안정.
- **수렴도/합의도**: 사분위범위(IQR) 기반 수렴·합의 지표.
- → 위 기준을 **사전에 하나로 고정**하고 모든 항목에 동일 적용.

### ④ 항목 처리 규칙
- 채택: 합의 기준 모두 충족
- 수정 후 재평정: 평정은 높으나 의견에서 표현·범주 수정 요구
- 탈락: CVR 임계값 미달 또는 안정도 불충족 지속

### ⑤ 산출물
- **합의된 최종 인지단계별 간호진단·중재·평가 프로토콜**
- 라운드별 합의 추이표(항목 수 변화, CVR/CV 변화)

### ⑥ 예상 소요기간
- **6~10주** (라운드당 3~4주 × 2라운드 내외)

### ⑦ 흔한 실수
- ✗ 피드백(집단 통계·의견) 미제공 → 그냥 설문 반복이 되어 델파이가 아니게 된다.
- ✗ 합의 기준을 결과 보고 나서 정하기 → 자의적 해석 비판. **반드시 사전 고정**.
- ✗ 라운드를 무한정 반복 → 패널 피로·탈락. 종료 규칙을 미리 정한다.
- ✗ CVR 임계값을 패널 수와 무관하게 고정(예: 무조건 0.5) → Lawshe 표에 맞춰야 한다.

## 4단계 — 결과 정리·논문화 (PROVE)

### ① 무엇을 하는가
- 최종 프로토콜의 **내용타당도 근거(CVR/CVI, 합의 추이)**를 정리·보고한다.
- 단계별 차별화 결과를 해석하고, 한계(조기검진 자료의 초기 편중 등)를 논한다.
- 학위논문/학술지 형식으로 작성한다.

### ② 준비물·지참물 체크리스트
- [ ] 라운드별 분석 결과·합의표
- [ ] 최종 프로토콜(매트릭스)
- [ ] 타당도 보고(CVR/CVI 표, 안정도)
- [ ] 보고지침 점검: 델파이 보고 권고(예: CREDES 등 합의연구 보고기준) 준수 체크

### ③ 산출물
- 학위논문 결과·고찰, 최종 프로토콜, (선택) 학술지 투고본

### ④ 예상 소요기간
- **8~12주**

### ⑤ 흔한 실수
- ✗ 합의 결과만 나열하고 **임상적 의미·적용 가능성** 해석을 빠뜨리기.
- ✗ 한계(자료원 편중, 패널 대표성) 미기술 → 심사 지적.
