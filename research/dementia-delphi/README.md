## 핵심 설계 결정 요약
1. **프레이밍**: "단계 간 차이 검정"이 아니라 **"단계별 차별화 프로토콜 개발 + 전문가 합의
   (내용타당화)"**. 델파이는 합의 도구다.
2. **두 데이터 소스**: 조기검진 평가자료 = *인지단계 분류 축*, EMR 간호기록 = *간호 항목 내용*.
   역할이 다른 별개 작업 흐름이며, 동일 단계분류 기준(CDR/GDS)으로 재정렬해야 비교가 성립.
3. **단계 분류**: CDR 1차 기준(0=정상, 0.5=MCI, 1~3=치매 경도·중등도·중증).
4. **합의 기준(사전 고정)**: CVR(패널 수별 Lawshe 임계값) + I-CVI ≥ 0.78 + CV ≤ 0.5.

## 주의
- `02`의 PubMed 인용은 모두 실제 검색으로 확인됨. 제출 전 각 DOI에서 서지정보 최종 대조.
- 국내 문헌(치매안심센터·CIST)은 RISS/KCI/DBpia 등 국내 DB로 보강 필요(PubMed 범위 밖).
- 본 묶음은 **계획 단계 자료**다. 실제 IRB 제출·자료수집·분석은 포함하지 않는다.
