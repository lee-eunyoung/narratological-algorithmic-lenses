# 연구설계 피드백 및 재구조화 (Research Design)

> **목적**: 현재 연구 구상을 비판적으로 점검하고, 박사논문 심사를 통과할 수 있도록
> 목적·변수·개념틀·방법을 재구조화한다. 핵심 산출물은 명료한 **개념틀**과 **방법-목적 정합성**.

---

## 1. 기존 구상의 진단된 문제와 교정

| # | 문제 | 왜 문제인가 | 교정 방향 |
|---|------|------------|-----------|
| 1 | **"단계 간 차이 검증"** 프레이밍 | 델파이는 집단 간 차이를 **통계 검정**하는 도구가 아니라 **전문가 합의**를 구축하는 도구. 방법-목적 불일치로 심사에서 지적됨 | 목적을 **"인지단계별로 차별화된 간호 프로토콜을 개발하고 전문가 합의로 내용타당화한다"**로 재정의 |
| 2 | 타당도 종류 모호 | 델파이 산출물은 **내용타당도(content validity)/전문가 합의**이지 준거·예측타당도가 아님 | "본 연구의 타당도는 **내용타당도(CVR/CVI)**"임을 명시. 준거타당도는 후속과제로 분리 |
| 3 | 항목 도출 경로 약함 | 평정할 항목이 어디서 오는지 불명확하면 도구의 신뢰가 무너짐 | **문헌 + 조기검진 자료 + EMR 간호기록** → 예비항목 → 델파이 → 합의안의 경로 확립 |
| 4 | 단계 분류 기준 미확정 | 정상/MCI/치매 세부단계 구분 기준이 없으면 자료 정렬 불가 | **4집단(정상·MCI·치매 CDR 0.5·치매 CDR 1)**으로 확정. MCI와 치매(CDR 0.5)는 CDR이 겹치므로 **CDR + 진단기준** 병용(아래 4절) |

## 2. 연구 목적·질문 (재진술)

**일반목적**: 치매 조기검진 자료를 토대로 인지장애 **4집단(정상 · MCI · 치매[CDR 0.5] ·
치매[CDR 1])**별로 차별화된 간호진단·간호중재·간호평가 프로토콜을 개발하고, 델파이 기법으로
내용타당도를 확보한다.

**세부목적**
1. (1차) 문헌·조기검진 평가자료·EMR 간호기록을 분석하여 단계별 간호과정 **예비 항목**을 도출한다.
2. (2차) 전문가 델파이를 통해 각 항목의 **내용타당도(CVR/CVI)**와 **합의**를 검증한다.
3. (3차) 합의된 **인지단계별 간호 프로토콜**을 확정하고 임상 적용 가능성을 제시한다.

**연구질문**
- RQ1. 각 인지단계에서 임상적으로 타당한 간호진단·중재·평가 항목은 무엇인가?
- RQ2. 어떤 항목이 전문가 합의(내용타당도 기준)를 충족하는가?
- RQ3. 단계 간에 간호과정은 어떻게 **차별화**되는가?

> ※ "차별화"는 통계적 유의차가 아니라 **합의된 항목 구성의 단계별 차이**로 기술한다(문제 #1 교정).

## 3. 핵심 변수와 조작적 정의

| 개념 | 조작적 정의 | 측정/판단 |
|------|------------|-----------|
| 인지단계(4집단) | 정상 / MCI / 치매(CDR 0.5) / 치매(CDR 1) | CDR + 진단기준(4절) |
| 간호진단 | 단계별 대상자의 실제·잠재 간호문제 | NANDA-I(또는 기관 표준간호용어) |
| 간호중재 | 진단에 대응하는 간호활동 | NIC(또는 표준중재 분류) |
| 간호평가 | 중재 결과의 기대성과 | NOC(또는 성과지표) |
| 내용타당도 | 항목이 개념을 적절히 대표하는 정도 | CVR(Lawshe), I-CVI/S-CVI |
| 합의 | 전문가 의견의 수렴·안정 | 변동계수(CV), IQR, 합의도 |

## 4. 단계 분류 기준 결정 (확정: 4집단)

**연구대상은 4집단으로 분류한다: ① 정상 · ② MCI · ③ 치매(CDR 0.5) · ④ 치매(CDR 1).**
CDR(Clinical Dementia Rating; Morris, 1993)을 1차 기준으로 하되, **MCI와 치매(CDR 0.5)는
CDR 점수가 같을 수 있으므로 진단기준(기능손상 유무)을 함께 적용**해 구분한다.

| 집단 | CDR | 추가 진단기준 | 영문 표기 |
|------|-----|--------------|-----------|
| ① 정상 | 0 | 인지 정상 | normal |
| ② MCI | 0.5 | 치매 진단기준 **미충족**(일상생활 독립 유지) | mild cognitive impairment |
| ③ 치매(CDR 0.5) | 0.5 | 치매 진단기준 **충족**(최경도) | very mild dementia |
| ④ 치매(CDR 1) | 1 | 치매 진단기준 충족(경도) | mild dementia |

- **핵심 주의(반드시 해결할 설계점)**: ②와 ③은 **CDR이 모두 0.5**일 수 있다. CDR 점수만으로는
  두 집단을 가를 수 없으므로, **임상 진단(예: DSM-5 주요/경도 신경인지장애 기준, 일상생활
  기능손상 유무)**을 병용해 집단을 배정한다. → **분류 축 = CDR 점수 + 진단기준.** 조작적
  정의(어떤 기준으로 ②/③을 나눌지)를 IRB 전에 명문화할 것.
  → 판정 절차 시각화: **`05-classification-algorithm.md`**(흐름도).
- **선정 근거**: 4집단은 조기검진이 실제로 포착하는 **초기 스펙트럼(정상 ~ 경도 치매)**에
  집중되어, 조기검진 자료의 강점 범위와 연구 범위가 **일치**한다(자료-설계 정합성↑).
- **범위 설정(의도적 경계)**: 중등도·중증(CDR 2~3)은 **연구 범위에서 제외**한다. 이는 조기검진
  자료의 초기 편중과 부합하는 의도적 결정으로, 앞서 지적된 "중증 자료 빈약" 문제를 **범위
  한정으로 해소**한다. 결과 해석 시 **적용 범위(초기 단계)**를 명시한다(한계는 `04` IV 참조).
- **GDS 병기(보조)**: 필요 시 GDS(Reisberg et al., 1982)를 보조 지표로 함께 기록한다
  (대략 GDS 1–2=정상, 3=MCI, 4=경도 치매).

## 5. 두 데이터 소스의 역할·절차 구분 (설계상 핵심)

> 사용자 질문("조기검진 평가자료와 EMR 간호기록은 진행단계가 다른가?")에 대한 설계상 답.

| 항목 | 조기검진 평가자료 | EMR 간호기록 |
|------|------------------|--------------|
| **연구 내 역할** | 인지단계 **분류 축**(어느 단계인가) | 간호 항목 **내용**(무슨 간호를 하나) |
| 대표 자료 | 신경심리 배터리(MMSE·단어목록기억·보스턴이름대기·단어유창성 = CERAD-K), SNSB, CDR/GDS | 간호진단·중재·경과·평가 기록(표준간호용어) |
| 자료 성격 | 횡단·지역사회·**초기 단계(정상~MCI)** | 종단·임상·**초기 치매(CDR 0.5~1) 간호 내용** |
| 출처/IRB | 치매안심센터·지자체 협조 | 병원 IRB·의무기록 열람 |
| 수집 시점 | 보통 먼저(분류 틀 확정) | 분류 틀 확정 후 또는 병행 |

**핵심 원칙**
1. 두 자료는 **역할이 다른 별개의 입력**이다. 섞지 말고 분류축/내용으로 분리한다.
2. 두 자료를 **동일한 단계분류 기준(CDR/GDS)으로 재정렬**해야 단계 간 비교·차별화가 성립한다.
3. 모집단·맥락이 다르므로(지역사회 검진 vs 임상 간호기록) 정합성 점검과 한계 기술이 필수.
   단, 연구 범위를 초기 단계(정상~CDR 1)로 한정해 두 자료의 포착 범위 불일치를 줄였다.
4. IRB가 기관별로 갈릴 수 있어 **일정·승인 관리가 두 갈래**가 된다.

## 6. 개념틀 (Conceptual Framework)

```
[입력]                         [처리]                        [산출]
─────────────────────         ─────────────────────         ─────────────────────
① 문헌 근거(02)         ┐
② 조기검진 평가자료 ────┤→ 인지단계 분류(CDR/GDS) ─┐
   (분류 축)            │                            ├→ 단계별 간호과정 예비 매트릭스
③ EMR 간호기록 ─────────┘→ 간호 항목 내용 추출 ──────┘   (NANDA-I→NIC→NOC)
   (내용)                                                        │
                                                                 ▼
                                          전문가 델파이(2~3R) · CVR/CVI/CV 합의
                                                                 │
                                                                 ▼
                                          ★ 합의된 인지단계별 간호 프로토콜(내용타당)
```

## 7. 연구방법 개요 (상세는 03·04)
- 설계: 방법론적 연구(도구·프로토콜 개발), 전문가 델파이 기법
- 대상: (자료) 조기검진·EMR 자료 / (패널) 치매 간호 전문가 10~20명
- 도구: 단계별 간호과정 평정 설문(Likert) + 개방형
- 분석: 기술통계, CVR(Lawshe), I-CVI/S-CVI, 변동계수(CV), IQR 합의지표
- 윤리: IRB 승인, 서면동의, 가명처리·보관·폐기 계획

## 8. 설계 점검 체크리스트
- [ ] 목적이 "합의·내용타당화"로 서술됨(통계적 차이검정 표현 제거)
- [ ] 타당도 종류가 "내용타당도(CVR/CVI)"로 명시됨
- [ ] 모든 예비 항목에 출처(문헌/조기검진/EMR) 표기 가능
- [ ] 단계 분류 기준(CDR/GDS) 단일 확정 및 매핑표 존재
- [ ] 두 자료의 역할 분리 + 동일기준 재정렬 + 한계 기술
- [ ] 개념틀 한 장으로 입력→처리→산출이 설명됨
